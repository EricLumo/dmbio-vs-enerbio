# 🌱 dmBio vs. enerBiO – Coupon-Preisvergleich

Ein Open-Source-Tool für die Community, um die Bio-Eigenmarken von **dm (dmBio)** und **Rossmann (enerBiO)** inklusive kombinierbarer App-Coupons (z. B. 10 % + 20 % bei Rossmann) fair anhand des Grundpreises zu vergleichen.

## 🚀 Features
- Dynamische Anpassung der aktuellen dm- und Rossmann-Coupons
- Automatische Berechnung der Kombinationsrabatte (z. B. 10 % auf alles + 20 % auf Ernährung = 28 % Gesamtrabatt)
- Fairer Vergleich über den Grundpreis (pro 100 g / 100 ml), auch bei unterschiedlichen Packungsgrößen
- Anzeige von Produkten, die nur bei einem der beiden Händler gelistet sind
